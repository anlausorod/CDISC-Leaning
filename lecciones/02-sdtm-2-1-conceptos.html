Conceptos y términos del modelo

SDTM es un marco general para organizar la información que se recoge en un estudio y se envía a las autoridades regulatorias. Todo el modelo descansa en tres ideas: observación, variable y dominio.

Las tres ideas base

Un conjunto de datos SDTM es un archivo plano, como una hoja de cálculo. Cada concepto del modelo tiene un lugar exacto en esa tabla.

Observación= una filaUna pieza discreta de información recogida durante el estudio.
Variable= una columnaUn dato con nombre que describe la observación. Cada variable tiene un Rol.
Dominio= un conjunto de datosObservaciones relacionadas lógicamente que comparten un tema, por ejemplo los eventos adversos.

Los 5 roles de una variable

El Rol dice qué tipo de información aporta la variable sobre cada observación y cómo puede usarse. Cada rol responde a una pregunta distinta.

Identificador

¿De quién y de qué registro hablamos?Identifica el estudio, el sujeto (una persona, un animal o un grupo), el dominio y el número de secuencia del registro.USUBJID DOMAIN --SEQ

Tema (Topic)

¿Sobre qué trata la observación?Marca el foco de la observación, como el nombre de una prueba de laboratorio o el término del evento adverso.--TERM --TRT --TESTCD

Tiempo (Timing)

¿Cuándo ocurrió?Describe el momento de la observación, como la fecha de inicio y la fecha de fin.AESTDY

Calificador (Qualifier)

¿Qué más sabemos de ella?Texto o valores numéricos que describen los resultados o rasgos adicionales, como unidades o adjetivos. Se divide en 5 subclases.AESEV --ORRESU

Regla (Rule)

¿Con qué condición empieza, termina o se repite?Expresa un algoritmo o método ejecutable para definir condiciones de inicio, fin o repetición. Solo se usa en el modelo de Diseño del Ensayo.

El código de dominio y sus cuatro usos

Cada dominio se distingue por un código único de dos caracteres, que debe usarse de forma consistente en todo el envío. Ese código aparece en cuatro lugares. Cambia de dominio para verlo.

Dominio:
1. Nombre del dataset
2. Valor de la variable DOMAIN
3. Prefijo de casi todas las variables
4. Valor de RDOMAIN en las tablas de relaciones
Los nombres de dominio son ejemplos habituales de las guías de implementación.

Metadatos: el documento define.xml

Cada dataset se entrega acompañado de un documento de definición de datos llamado «define», que describe sus variables. Define.xml usa siete atributos por variable. Aquí los tienes aplicados a AETERM.

AtributoEjemploQué exige el modelo
NombreAETERMMáximo 8 caracteres, por compatibilidad con el formato SAS Transport.
EtiquetaReported Term for the Adverse EventDescriptiva, hasta 40 caracteres y única dentro del dataset.
TipoCharSolo carácter o numérico (limitación de SAS v5 transport).
Términos controlados o formato—La terminología controlada de los valores, o su formato de presentación.
OrigenCRFDe dónde procede la variable. Usa terminología controlada de CDISC.
RolTopicCómo se usa la variable: Identificador, Tema, Tiempo o uno de los cinco calificadores.
ComentariosTexto libreLo que el patrocinador necesite explicar a la agencia sobre la variable o sus datos.

Datos crudos y derivados

Las variables guardan valores crudos, tal como los capturó quien aportó los datos, y valores derivados, como una conversión a unidades estándar o la edad calculada.

Qué fija SDTM y qué viene después

SDTM define nombre, etiqueta, rol y tipo de las variables estándar. Se espera que en el futuro haya tipos más descriptivos (entero, decimal, fecha, fecha/hora) cuando cambie el requisito de SAS v5.

Reglas para el patrocinador

Al preparar un envío, el patrocinador tiene un margen muy acotado sobre las variables.

  • PermitidoOmitir variables definidas como permisibles en la guía de implementación, y su descripción en define.xml, siempre que no se haya recogido ningún dato para ellas.
  • ProhibidoAñadir variables nuevas definidas por el patrocinador.
  • ProhibidoRenombrar variables existentes o modificarlas para un uso distinto.
  • ConsultarLa guía de implementación correspondiente indica qué variables son requeridas, esperadas o permisibles en cada dominio.
